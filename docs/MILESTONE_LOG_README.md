# Global20Engine Milestone Log CSV

Primary milestone source-of-truth file:

`docs/GLOBAL20ENGINE_MILESTONE_LOG.csv`

Use CSV as the main governance tracker because it is easy to filter by milestone, phase, status, verification state and next action.

Recommended rule:
- CSV = operational milestone tracker
- Markdown = optional readable summary only

Do not mark a milestone as `VERIFIED` until output evidence is checked.
